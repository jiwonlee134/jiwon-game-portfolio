# 이지원 게임 개발 포트폴리오

AI와 대화하며 게임을 기획하고, 구현·테스트·오류 해결·개선을 반복해 완성한 개인 포트폴리오입니다.

## 대표 프로젝트

### SECTOR NINE: BREACH

폐쇄된 네온 구역에 침투해 적 요원을 제압하고 데이터 코어를 회수하는 브라우저 기반 1인칭 슈팅 게임입니다.

- 레이캐스팅 기반 1인칭 원근 공간
- WASD 이동, 마우스 시점, 사격, 재장전 및 달리기
- 탄창, 반동, 피격, 점수와 콤보 시스템
- 절차형 느와르 BGM과 효과음
- 적 시야, 추적, 공격과 벽 충돌 처리

## 실행 방법

별도의 설치나 빌드 없이 `deploy/index.html`을 브라우저에서 열면 됩니다.

```text
deploy/index.html
```

`main` 브랜치에 코드가 업로드되면 GitHub Actions가 `deploy` 폴더를 GitHub Pages에 자동 배포합니다.
