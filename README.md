# 이지원 게임 개발 포트폴리오

AI와 대화하며 게임을 기획하고, 구현·테스트·오류 해결·개선을 반복해 완성한 개인 포트폴리오입니다.

## 대표 프로젝트

### NEON REQUIEM: Midnight Run

90초 동안 추적 드론을 제거하고 자정까지 생존하는 브라우저 기반 액션 게임입니다.

- 사람 형태의 플레이어 캐릭터와 보행 애니메이션
- 이동, 조준, 사격, 재장전 및 대시 조작
- 탄창, 반동, 피격, 점수와 콤보 시스템
- 절차형 느와르 BGM과 효과음
- 데스크톱 및 모바일 조작 지원

## 실행 방법

별도의 설치나 빌드 없이 `deploy/index.html`을 브라우저에서 열면 됩니다.

```text
deploy/index.html
```

## 기술

- HTML
- CSS
- JavaScript
- Canvas API
- Web Audio API
- AI-assisted Vibe Coding

## 배포

`main` 브랜치에 코드가 업로드되면 GitHub Actions가 `deploy` 폴더를 GitHub Pages에 자동 배포합니다.
