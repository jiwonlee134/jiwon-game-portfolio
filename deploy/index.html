06REAL PROBLEM CASES

FROM PROBLEM TO DECISION

과정이 아니라,
해결의 증거.

CASE 01

적 캐릭터가
한곳에 겹쳤다.

PROBLEM
모든 적이 플레이어만 향해 이동하면서 같은 좌표에 겹쳐 전투 상황이 잘 보이지 않았습니다.
CAUSE
적과 적 사이의 거리 판단 없이 동일한 추적 방향만 계산하고 있었습니다.
SOLUTION
가까운 적끼리 서로 밀어내는 분리 벡터를 추적 방향에 더했습니다.
RESULT
적이 무리를 유지하면서도 자연스럽게 퍼져 전투의 가독성이 좋아졌습니다.
CASE 02

플레이어가
기계처럼 보였다.

PROBLEM
삼각형 형태의 플레이어는 조작 대상이 사람이라는 인상을 주지 못했습니다.
CAUSE
방향과 위치 전달에만 집중해 인체를 구분할 시각 정보가 부족했습니다.
SOLUTION
머리, 머리카락, 코트, 양팔, 손, 다리와 권총을 분리해 그렸습니다.
RESULT
위에서 보는 작은 화면에서도 사람과 무기의 방향을 구분할 수 있게 됐습니다.
CASE 03

사격의 무게감이
부족했다.

PROBLEM
탄약 제한 없이 같은 속도로 발사되어 사격이 단순한 클릭처럼 느껴졌습니다.
CAUSE
발사 성공 여부만 구현되어 총기의 물리적 피드백이 없었습니다.
SOLUTION
탄창, 재장전, 반동, 탄피, 궤적, 화면 흔들림과 다층 총성을 추가했습니다.
RESULT
사격과 이동 사이에 선택이 생기고 전투의 긴장감이 강화됐습니다.
