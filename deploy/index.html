06REAL PROBLEM CASES

FROM PROBLEM TO DECISION

과정이 아니라,
해결의 증거.

CASE 01

평면 지도를
입체 공간으로.

PROBLEM
2차원 좌표만으로는 플레이어가 통로 안을 걷는 1인칭 경험을 만들 수 없었습니다.
CAUSE
벽까지의 거리와 시야 각도에 따른 원근 표현이 없었습니다.
SOLUTION
화면의 세로줄마다 광선을 발사해 가장 가까운 벽의 거리와 높이를 계산했습니다.
RESULT
Canvas 하나만으로 이동 가능한 3차원 형태의 미로 공간을 구현했습니다.
CASE 02

마우스 움직임을
시선으로 바꿨다.

PROBLEM
화면 위 커서를 움직이는 방식은 1인칭 시점의 몰입감을 만들지 못했습니다.
CAUSE
마우스 위치와 카메라 회전값이 서로 연결되지 않았습니다.
SOLUTION
Pointer Lock API의 이동량을 카메라 각도로 변환하고 화면 중앙에 조준점을 고정했습니다.
RESULT
마우스를 움직이는 방향대로 즉시 주변을 살필 수 있는 FPS 조작이 완성됐습니다.
CASE 03

사격의 무게감이
부족했다.

PROBLEM
화면 중앙에서 판정만 발생하면 총을 쏘는 동작과 결과가 분리되어 보였습니다.
CAUSE
무기 모델, 반동, 총구 화염과 음향 피드백이 없었습니다.
SOLUTION
1인칭 손과 권총, 탄창, 재장전, 반동, 화면 흔들림과 다층 총성을 추가했습니다.
RESULT
발사 입력과 시각·청각 반응이 동시에 연결되어 전투의 긴장감이 강화됐습니다.
